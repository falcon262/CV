## Context

A US insurance carrier needed a commissions platform built from scratch, covering the whole commission lifecycle from onboarding a broker to paying them by ACH. I was the technical lead. The platform spans 44 business domains and more than 75 REST APIs, with a .NET 9 API behind a React front end.

## The problem

Commission money passes through several stages before it reaches a broker. It is calculated, recorded in the accounts and then paid, and each stage has to agree with the one before it.

Payment is the least forgiving stage. The bank validates every ACH file against the NACHA specification, so a file has to match that specification exactly: every record, every field and every control total.

## What I did

I built the NACHA/ACH payment file library directly from the NACHA specification. The library follows the specification record by record and field by field, so every line of a generated file can be checked against the document the bank uses.

I built the general ledger accounting subsystem, so commission activity is recorded in the accounts on its way from calculation to a payment file.

I introduced a modular OpenAPI specification strategy with automated TypeScript client generation. The React front end talks to the .NET API through generated, type-safe clients rather than hand-written ones.

I designed a reusable three-layer report architecture: a controller, a rendering service and a data service, with QuestPDF for PDF output and ClosedXML for Excel. The same pattern was later reused successfully on a second platform.

Background processing runs on Hangfire, and I integrated ClickHouse for commission calculations.

## Outcome

The carrier has one greenfield platform for the whole commission cycle, from broker onboarding to ACH payment. Payment files come from a library built against the NACHA specification itself, commission activity runs through a general ledger accounting subsystem, and the front end stays in step with the API through generated clients. The report architecture proved general enough to be reused on a second platform.
